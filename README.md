## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第13章 事实核查与开源情报**（教材 Tier 1 实验工具）。教材命名："太阳阴影/地理定位推算仪"（基于 SunCalc 算法）。

**学习目标**：理解太阳高度角、方位角与阴影方向的对应关系，能用 SunCalc 算法核验照片声称的拍摄时间与地点是否自洽。

**核心术语**：开源情报（OSINT）、地理定位（Geolocation）、太阳方位角（Solar Azimuth）、阴影验证（Shadow Verification）

**适合对象**：事实核查爱好者、新闻传播专业学生、调查记者

**课前准备**：按教师布置准备一张待验证照片，并抄录三项线索——照片声称的拍摄地点经纬度、声称的拍摄当地时间、照片中阴影的方向（如"影子朝向画面左下方"，可对照工具中的罗盘估算方位角）；本工具基于 SunCalc 算法本地计算，打开即用、离线可用。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师载入工具内置案例，输入声称的经纬度与当地时间，演示工具算出的太阳高度角、太阳方位角与阴影方位角，讲解"照片里的影子方向对不上 → 时间或地点组合存疑"的完整推理链
2. **上手实操**（20 分钟）：学生两人一组核验待验证照片：把声称的经纬度、当地时间与观察到的阴影方位角逐项填入工具→记录太阳高度角、太阳方位角、阴影方位角的计算结果→与照片实际阴影比对，在教师指导下、合法合规地给出"一致/存疑"结论并写明依据→再用工具反推：若阴影属实，真实拍摄时间应在何时
3. **小组讨论**（8 分钟）：阴影验证能证伪"时间+地点"组合，却不能单独证实照片为真——还需哪些证据（天气记录、卫星图、EXIF 元数据）交叉印证？
4. **总结**（4 分钟）：太阳位置是任何人无法伪造的"天体时钟"，阴影核验是地理定位的硬校验。

**课后作业**：自选一张带明确时间地点声称的新闻照片（在教师指导下、合法合规地选取），用工具完成阴影核验并写 300 字核查报告。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
